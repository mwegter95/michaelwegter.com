The engineering behind it

This customizer is the fix, not the bug

The posting described a customizer bleeding conversions to dead clicks, console errors, and a bouncing homepage. This demo is built the way that store should have been. Below is the exact before / after mapping and the remediation roadmap your current team can execute.

Clarity findingRoot causeThis build's fix
Dead clicks + "undefined is not an object" on color / design swapsUnguarded nested state reads; the customizer touches store fields before async hydration finishes.Zustand selectors with safe defaults, no unguarded optional chaining. Every read resolves to a value or a fallback, never undefined.
Homepage bounce: instant exits right after loadHeavy synchronous JS (the 3D / canvas lib) sits in the critical path and blocks first paint.next/dynamic with ssr:false code-splits Three.js out of the initial bundle. The homepage is interactive and painted before the canvas ever mounts.
Unresponsive color swaps / laggy UIMultiple setState calls per interaction trigger cascading re-renders and layout thrash.One atomic Zustand action per interaction; the 3D material updates a single prop per frame instead of re-rendering the tree.
Share / save silently fails when an API is downFetch rejects, the handler throws, the click looks "dead".Every network call is wrapped: on failure the design is encoded into the share URL client-side, so the feature degrades instead of dying.

Remediation roadmap

  1. 1Audit every selector call for undefined; wrap with ?? fallback or an early return.
  2. 2Move Three.js / canvas to a dynamic import with ssr:false. Measure LCP before and after.
  3. 3Replace setState chains with a single store action that patches multiple fields atomically.
  4. 4Wrap the Canvas in an ErrorBoundary and log failures to Clarity custom events.
  5. 5Re-run the Clarity Dead-Click heatmap against the patched build and confirm the hot zones clear.

Stack

  • ▸ Next.js 15 static export, code-split 3D bundle
  • ▸ React Three Fiber + drei for the live 3D shirt
  • ▸ Zustand single-source state, no cascading re-renders
  • ▸ PHP microservice for save / share, proxied through a Flask (Python) API
  • ▸ Graceful degradation: every network path has a client-side fallback
